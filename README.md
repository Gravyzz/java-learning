# Java Learning

Здесь я тренируюсь и учу Java — пишу код, разбираю темы и делаю небольшие проекты.

Это мой учебный репозиторий: тут собраны примеры, заметки и пет-проекты, которые я делаю по мере изучения языка.

## Что внутри

Весь код лежит в `Learn/src/`:

| Тема | Папка |
|------|-------|
| Generics (обобщения) | `Generics/` |
| Коллекции | `Collection/` |
| Лямбды и Stream API | `lambdasAndStreamAPI/` |
| Static, исключения, классы | `StaticDemo/` |
| Проект «Библиотека» | `Library_Project/` |
| Проект «Коворкинг» | `Workspace_project/` |
| Проект «Банк» | `Bank_project/` |
| Разные упражнения | `Workout/` |

## Как запускать

Любой класс с методом `main` можно запустить так:

```bash
cd Learn/src
javac путь/к/Main.java
java путь.к.Main
```

Или просто открыть проект в IntelliJ IDEA и запустить нужный `Main`.
